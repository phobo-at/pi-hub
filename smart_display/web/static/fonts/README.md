`atkinson-hyperlegible-next-variable.woff2` ist die lokal ausgelieferte
UI-Schrift. Dadurch bleibt die Darstellung auf Chromium und Cog identisch und
funktioniert vollständig offline. Sie deckt die verwendeten Schnitte von 400
bis 700 in einer 47-KB-Datei ab.

Quelle: `googlefonts/atkinson-hyperlegible-next`, Commit
`7925f50f649b3813257faf2f4c0b381011f434f1`. Die Schrift steht unter der SIL
Open Font License 1.1; der vollständige Text liegt in
`atkinson-hyperlegible-next-OFL.txt`.

`Inter` bleibt als Systemschrift für die bewusst unveränderten QLOCKTWO-Faces
installiert. `Noto Sans` ist der Fallback für fehlende Glyphen.
